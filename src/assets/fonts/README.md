Noto Sans and Noto Serif variable fonts, downloaded from google/fonts (ofl/notosans and ofl/notoserif). SIL Open Font Licenses are included. Local WOFF2 subsets retain Latin, Latin Extended, Vietnamese, combining diacritics and common punctuation. Each face contains both base letters and combining marks to support NFC and NFD text without cross-font fallback. Generated with fontTools subset, all shaping features preserved. No runtime font service is used.
